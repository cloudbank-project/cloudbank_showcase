# CloudBank Showcase

Practical tutorials that show how to run real-world scientific applications
on cloud resources accessed through [CloudBank](https://www.cloudbank.org/),
covering both AWS and Google Cloud.

## Tutorials

| Tutorial | Cloud Provider | Resources | Difficulty | Estimated Time |
|----------|----------------|-----------|------------|----------------|
| [GPU Computing in Oceanography](/tutorials/gpu-oceanography/overview) | <span class="badge badge--primary">Google Cloud</span> | GPU instances, JupyterHub, Julia/Reactant.jl | <span class="badge badge--warning">Intermediate</span> | 1-2 hours |
| [Knowledge Graphs for Chemistry](/tutorials/knowledge-graphs-chemistry/overview) | <span class="badge badge--secondary">AWS</span> | S3, Neptune, EC2, Fargate, SPARQL | <span class="badge badge--warning">Intermediate</span> | 1-2 hours |
| [Cloud Seismology Analysis](/tutorials/cloud-seismology/overview) | <span class="badge badge--secondary">AWS</span> | EC2, S3, Docker, NoisePy | <span class="badge badge--warning">Intermediate</span> | 2-3 hours |
| [Toy Data Portal for Hydrology](/tutorials/toy-data-portal/overview) | <span class="badge badge--primary">Google Cloud</span> | GKE Autopilot, Cloud Storage, JupyterHub | <span class="badge badge--success">Beginner</span> | 1-2 hours |

Every tutorial includes step-by-step guides, Jupyter notebooks rendered
statically in the browser, and cloud provider specifics.

> The footer of every page shows exactly when this site was last built, so
> you can tell how fresh this documentation is.
