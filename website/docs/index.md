# CloudBank Showcase

Work-in-progress repository of demo/tutorials that showcase how to use Cloud
resources provided by [CloudBank](https://www.cloudbank.org/) in
real-world scientific applications.

## Tutorials

| Tutorial | Cloud Provider | Resources | Difficulty | Estimated Time |
|----------|----------------|-----------|------------|----------------|
| [GPU Computing in Oceanography](/tutorials/gpu-oceanography/overview) | Google Cloud | GPU instances, JupyterHub, Julia/Reactant.jl | Intermediate | 1-2 hours |
| [Knowledge Graphs for Chemistry](/tutorials/knowledge-graphs-chemistry/overview) | AWS | S3, Neptune, EC2, Fargate, SPARQL | Intermediate | 1-2 hours |
| [Cloud Seismology Analysis](/tutorials/cloud-seismology/overview) | AWS | EC2, S3, Docker, NoisePy | Intermediate | 2-3 hours |
| [Toy Data Portal for Hydrology](/tutorials/toy-data-portal/overview) | Google Cloud | GKE Autopilot, Cloud Storage, JupyterHub | Beginner | 1-2 hours |

Every tutorial includes step-by-step guides, Jupyter notebooks rendered
statically in the browser, and cloud provider specifics.
